- **Faithfulness** is an LLM-as-judge score (one judge model, no human labels). Some flagged

  invents "set the timer to 0", q31 speculates about causes, q30 "apply cleaner to the cloth").
  Faithfulness 0.931 means ≈7% of answer claims were not directly supported by the retrieved text.

  the paper table on p.131 instead of p.133). Citation precision 0.78 includes legitimate extra
  citations (cross-referenced procedures).

  detector missed that phrasing. The detector was widened and stored answers re-scored, not regenerated.
- **Follow-ups/memory:** the first run scored f02 memory/isolation 0/1 because a rate-limited
  (failed) attempt was written to the session before the retry, duplicating the user turn. Product fix:
  failed generations are no longer stored in memory; the follow-up block was re-run (3/3).
- Precision@5 is low for every strategy by construction: most questions have only 1–2 relevant chunks
  among five slots.
